Marrow — Privacy Policy

Last updated: 2026-05-31  |  App version: v0.64.0+
Short version
  • Marrow does not collect any data
  • Marrow does not send anything to any server — ever
  • Marrow does not require an account
  • Marrow does not show ads
  • All sensor readings stay on your device and are displayed then discarded

What Marrow reads

Marrow reads sensor and system data from your device in order to display it on screen. All reads are local and on-device. Nothing is transmitted anywhere.

Battery — charge level, health %, cycle count, temperature, voltage, current, power draw, and charge state. Read via BatteryManager and /sys/class/power_supply/battery/.

CPU & Memory — per-core frequencies (via /sys/devices/system/cpu/), total CPU load (via /proc/stat), RAM usage (via ActivityManager), zRAM state.

Storage — used / free / total storage per volume (via StatFs). Live disk I/O read/write rates (via /proc/diskstats).

Network — Wi-Fi signal strength, link speed, frequency band, SSID, VPN status, Bluetooth state, NFC state, airplane mode, hotspot state, local IP address, network traffic totals (TX/RX bytes since boot via TrafficStats). No network requests are made.

Display — screen brightness %, adaptive brightness mode, screen refresh rate, ambient light sensor (lux), dark mode state, auto-rotate state, screen timeout setting, resolution, pixel density.

Audio — ringer mode, media/ring/alarm volume %, music playing state, Do Not Disturb mode.

Environment sensors — barometric pressure, ambient temperature, device tilt, magnetic field strength, proximity distance. Read via SensorManager. Available only on devices that have these hardware sensors.

Activity sensors — step count since reboot (via TYPE_STEP_COUNTER), compass bearing (via TYPE_ROTATION_VECTOR), gyroscope rotation rate, linear acceleration. Read via SensorManager. Zero permissions.

Location — latitude, longitude, altitude, speed, bearing, accuracy, and fix age. Read only when you grant the ACCESS_FINE_LOCATION permission. Never stored, never transmitted. The permission is opt-in: a prompt appears when you open the Location section; the app works fully without it.

Cellular — carrier name, SIM state, network type (5G / LTE / 3G / 2G), signal bars, roaming status. Read via TelephonyManager. Uses READ_BASIC_PHONE_STATE (a "normal" permission — no dialog on Android 13+; degrades gracefully on older versions).

Heart rate (Wear OS only) — beats per minute from Sensor.TYPE_HEART_RATE. Read only when you grant BODY_SENSORS on the watch. Never stored, never transmitted. Opt-in: a prompt appears in the Wear app.

What Marrow does not do

  • Does not send data to any server, API, or analytics endpoint
  • Does not store any sensor readings beyond what is visible on screen
  • Does not collect usage analytics or crash reports
  • Does not display advertisements
  • Does not require a login or account
  • Does not use the internet (no INTERNET permission in the manifest)
  • Does not track you across apps or sessions
  • Does not write sensor data to files on your device

Permissions declared

ACCESS_FINE_LOCATION ACCESS_COARSE_LOCATION — GPS section only, opt-in, never stored
BODY_SENSORS — Wear OS heart rate only, opt-in, never stored
READ_BASIC_PHONE_STATE — carrier / signal info, normal permission, no dialog on Android 13+
ACCESS_NETWORK_STATE ACCESS_WIFI_STATE — Wi-Fi info (no internet access)
ACTIVITY_RECOGNITION — step counter
BIND_COMPLICATION_DATA_SOURCE — Wear OS battery and RAM complications

Data retention

Marrow does not retain sensor data. Values are read, displayed, and discarded when the screen updates (typically every 2 seconds). The only persistent state is UI preferences (which section is expanded), stored locally via Android's standard preferences API.

Children's privacy

Marrow does not collect any data from any user, including children. The app is rated "Everyone" on Google Play.

Changes to this policy

If Marrow ever adds a feature that involves data collection or transmission, this policy will be updated and the "Last updated" date will change. Given Marrow's philosophy (local-only, no network permission), this is not anticipated.
